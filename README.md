# Camouflaged Reptilians Minecraft Plugin

The Camouflaged Reptilians plugin adds a unique twist to your Minecraft server by introducing reptilian villagers that can camouflage among the regular villagers. These reptilian villagers have distinct behaviors and appearances, and players can use specific items to reveal their true forms. The plugin includes eight types of reptilian villagers, each with unique abilities and characteristics. This plugin is perfect for server owners looking to add a new layer of excitement and strategy to their gameplay.

## Install

1. Download the plugin JAR file from the releases section of the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart your server to load the plugin.

## Use

1. **Camouflage a Villager**: Use the command `/reptilian camouflage <type>` while targeting a villager to turn it into a reptilian villager of the specified type. Replace `<type>` with one of the following: SERPENT, CROCODILE, GECKO, TORTOISE, KOMODO_DRAGON, CHAMELEON, BASILISK, ALPHA_PRIMAL_SPECIES.
2. **Reveal a Reptilian Villager**: Use the command `/reptilian reveal` while targeting a camouflaged reptilian villager to reveal its true form.
3. **Interact with Reptilian Villagers**: Right-click on a camouflaged reptilian villager with a specific item (e.g., a stick) to reveal it.
